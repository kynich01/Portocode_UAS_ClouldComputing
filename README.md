# Kynich Portfolio — "KyPort"
Website portofolio pribadi berbasis HTML, CSS, dan JavaScript yang menampilkan project coding dan hasil editing video/motion graphic.

---

## Fitur Utama
- Tampilan dark mode dengan tiga white lightning  
- Progress bar scroll di bagian atas navbar
- Animasi reveal
- Highlight otomatis pada menu navigasi sesuai section aktif
- Menu navigasi responsif dan hamburger menu untuk tampilan mobile
- Form kontak terhubung ke layanan Formspree agar pesan langsung masuk ke email

---

## Teknologi yang Digunakan
| Teknologi | Keterangan |
|-----------|------------|
| HTML5 | Struktur konten website |
| CSS3 | Styling, animasi, dan tata letak responsif |
| JavaScript | Interaktivitas (scroll, navigasi, form) |
| Font Awesome & Simple Icons | Ikon |
| Google Fonts | Tipografi (Space Grotesk, Plus Jakarta Sans) |
| Formspree | Layanan pengiriman form kontak tanpa backend |
| GitHub Pages | Hosting gratis |

---

## Struktur Halaman
- **Beranda** — perkenalan singkat, tagline, tombol aksi cepat, dan tautan sosial media
- **Tentang** — cerita singkat serta fokus/peran yang diminati
- **Proyek** — daftar project coding dan hasil editing video
- **Keunggulan** — poin-poin nilai jual penulis di bidang mobile development dan editing
- **Skill** — kemampuan teknis dikelompokkan per kategori
- **Kontak** — tautan sosial media serta form pengiriman pesan

## Cara Menjalankan
1. Clone repository ini
2. Masuk ke folder project
3. Buka file `index.html` langsung di browser, atau jalankan lewat Live Server (VS Code)

## Form Kontak
Form kontak terhubung ke layanan [Formspree](https://formspree.io), sehingga pesan yang dikirim pengunjung akan langsung masuk ke email developer tanpa perlu membuka aplikasi email.
